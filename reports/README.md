# Reportes

Esta carpeta contiene los dos entregables analiticos del proyecto.

## Archivos

- `onpe_peru_2026-1.pbix`: dashboard en Power BI.
- `onpe_peru_2026-1.xlsx`: analitico en Excel con Power Query y pivotes.

## Fuente de datos

Ambos reportes se alimentan del output de:

- https://github.com/oscarzamora/onpeescraper

Salidas usadas:

- `output/mesas_data.txt`
- `output/votos.txt`
- `output/agrupaciones.txt`

## Mantenimiento

Para refrescar reportes, seguir la guia en:

- `docs/refresh-reportes.md`
